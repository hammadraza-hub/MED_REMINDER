# Report fonts (M17)

Used only to embed in the PDF report, so Latin, Devanagari (Hindi) and Arabic text can be printed.

| File | Family | Used for |
|---|---|---|
| NotoSans-Regular.ttf, NotoSans-Bold.ttf | Noto Sans | English, Spanish, French and all numbers |
| NotoSansDevanagari-Regular.ttf | Noto Sans Devanagari | Hindi (fallback for any Devanagari character) |
| NotoNaskhArabic-Regular.ttf | Noto Naskh Arabic | Arabic (fallback for any Arabic character) |

Source: https://github.com/notofonts/notofonts.github.io (folder `fonts/<Family>/hinted/ttf`).
